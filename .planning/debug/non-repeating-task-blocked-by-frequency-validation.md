# Debug: создание неповторяющейся задачи блокируется валидацией частоты

- **Дата:** 2026-07-25
- **Кто нашёл:** пользователь
- **Источник:** BUGF-03 (Phase 2 — runtime-валидация), баг предшествует Phase 3
- **Симптом:** При создании **неповторяющейся** задачи в модалке падает ошибка «Частота повторения должна быть положительным целым числом», задачу создать невозможно.
- **Ожидание:** если переключатель «повторяющееся дело?» выключен, создаётся неповторяющаяся задача без проверки частоты.

## Причина

`onCreate` в `components/AddTodo/AddTodo.tsx` выполнял проверку частоты **безусловно**:

```ts
if (!isValidRepeatFrequency(Number(repeatFrequency))) { ... return; }
```

Состояние `repeatFrequency` — строка с дефолтом `""`. Для неповторяющейся задачи поле пустое → `Number("")` === `0` → `isValidRepeatFrequency(0)` === `false` (проверка `Number.isInteger(value) && value > 0`, а `0` не `> 0`) → ошибка и ранний `return`.

Более ранняя проверка (`if (isRepeat && !repeatFrequency)`) была правильно ограничена `isRepeat`, а проверка `isValidRepeatFrequency` — нет.

## Исправление

Ограничить проверку частоты тем же условием `isRepeat`:

```ts
if (isRepeat && !isValidRepeatFrequency(Number(repeatFrequency))) { ... return; }
```

- Неповторяющаяся задача (`isRepeat === false`): проверка пропускается, задача сохраняется с `repeatFrequency: 0` (как и прежде; бейдж повтора рендерится только при `repeatFrequency > 0`).
- Повторяющаяся задача: валидация сохраняется — `repeatFrequency` = `0` / отрицательное / дробное по-прежнему отклоняется.

## Проверка

- `npx tsc --noEmit` → 0.
- Ручной сценарий: создать задачу с выключенным переключателем повтора → задача создаётся без ошибки; создать повторяющуюся с частотой `0`/пусто → ошибка по-прежнему показывается.

## Затронутые файлы

- `components/AddTodo/AddTodo.tsx` — условие проверки `isValidRepeatFrequency` (строка ~176).
