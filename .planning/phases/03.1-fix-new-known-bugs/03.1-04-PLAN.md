Сейчас значение по умолчанию (`new Date()` в момент включения) гарантированно оказывается в прошлом к моменту сохранения.

## Флаговые допущения (edge-probe: unresolved)

- **BUGF-10 — unclassified** (edge-probe не классифицировал требование). Допущения планировщика: время, равное текущему моменту, считается прошедшим (`!isAfter(remindDate, new Date())`); пикер времени обнуляет секунды, поэтому выбор текущей минуты отклоняется. Проверка выполняется в момент нажатия «Сохранить». **Не проверяется**: смена суток или часового пояса между открытием формы и сохранением; напоминание раньше даты задачи, если дату задачи изменили после включения напоминания (пикер даты напоминания ограничен `minimumDate={nextDate}`, но уже выбранное напоминание не пересчитывается) — вне BUGF-10.
- **D-02, 23:xx (зафиксировать в SUMMARY как известное поведение):** для задачи на сегодня при включении напоминания в 23:xx значение по умолчанию — 00:00 следующего дня, то есть уже не на дате задачи. Это сознательный выбор по делегированию D-02 («крайние случаи — на усмотрение планировщика при условии, что значение по умолчанию для задачи на сегодня всегда в будущем»): требование «всегда в будущем» приоритетнее, чем «на дату задачи»; пользователь может поменять значение пикером до сохранения.
