<objective>
Убрать тихий перенос прошедшего времени напоминания на now + 60 с (D-04, серверная половина BUGF-10) и сделать сбой планирования напоминания видимым и консистентным (BUGF-09, D-05, D-06): задача сохраняется без `reminderDate`/`notificationId`, пользователь получает сообщение с причиной.

Цель (Purpose): сейчас `getEffectiveReminderDate` в `hooks/useNotifications.ts` молча подменяет прошедшее время и записывает в задачу время, которого пользователь не выбирал, а при исключении `scheduleNotification` в `hooks/useTodos.ts` задача сохраняется с `reminderDate`, для которого уведомления нет (старое при редактировании уже отменено). Валидация формы (клиентская половина BUGF-10, D-01…D-03) — план 03.1-04; сбой при выполнении повторяющейся задачи (D-07) — план 03.1-03, он использует хелпер `notifyReminderFailed` из этого плана.

Результат (Output): `hooks/useNotifications.ts` без функции подмены даты, с ранним возвратом для прошедших дат и экспортом `notifyReminderFailed`; `hooks/useTodos.ts` с консистентной обработкой сбоя; `components/Todo/Todo.tsx` минимально адаптирован к новому типу результата `rescheduleNextNotification` (полная переработка выполнения — план 03.1-03).
