## Pattern Assignments

### `utils/time.ts` (utility, transform) — BUGF-06

**Analog:** `utils/todoFilters.ts` строки 1-11 (эталон локального парсинга) и стиль `utils/time.ts` (чистые экспортируемые функции без React).

```typescript
import { isAfter, isBefore, isSameDay, parse, startOfDay } from "date-fns";
export const isExpired = (todo: TodoItem, now: Date = new Date()): boolean =>
  isBefore(parse(todo.nextDate, "yyyy-MM-dd", new Date()), startOfDay(now));
```

Добавить рядом с `parseTime`/`formatTime` (уже есть `formatTime(date)` на `getHours()`, локальное время):
```typescript
import { format, parse } from "date-fns";
export const parseDateKey = (key: string): Date => parse(key, "yyyy-MM-dd", new Date());
export const toDateKey = (date: Date): string => format(date, "yyyy-MM-dd");
```
Затем заменить в `todoFilters.ts` три `parse(todo.nextDate, ...)` на `parseDateKey(todo.nextDate)`. `sortByDate` (localeCompare по строке) корректен — не трогать.

### `components/Todo/Todo.tsx` (component, CRUD) — BUGF-05/06/07/08, D-07..D-10


**BUGF-07 / D-08:** `showAlert` (стр. 56-63) сейчас `onPress: getAllTodos`. Вызывать `await getAllTodos()` сразу после `handleCompleteTask`/`removeTodo`, а `showAlert` оставить с `[{ text: "OK" }]`. В `showAlertForExpiredTask` уже есть `await getAllTodos()` после `handleCompleteTask` внутри onPress (стр. 83, 96) — паттерн правильный, но в ветках `onTaskComplete` (стр. 118-141) его нет.

### `storage/todoStorage.ts` (storage, CRUD) — BUGF-08

```typescript
export const updateTodo = async (id: number, todo: TodoItem) => {
    const todos = await loadTodos();
```

## Shared Patterns

### Сообщения пользователю
**Source:** `hooks/useTodos.ts` стр. 31 — `Alert.alert("Ошибка", "Не удалось загрузить список задач");`
**Apply to:** D-05/D-06/D-07 (`useTodos.ts`, `Todo.tsx`). Один общий хелпер в `hooks/useNotifications.ts`, чтобы тексты не дублировались.

### Календарные даты
**Source:** `utils/todoFilters.ts` стр. 5 (`parse(x, "yyyy-MM-dd", new Date())`) -> `parseDateKey`/`toDateKey` в `utils/time.ts`.
**Apply to:** `WeekStrip.tsx`, `Todo.tsx`, `recurrence.ts`, `AddTodo.tsx`, `todoFilters.ts`. Критерий: `grep 'new Date(.*nextDate'` и `toISOString().split` в коде пусто. `reminderDate` (полный ISO) парсить через `new Date(iso)` — это корректно.

### Отмена уведомления без блокировки
**Source:** `Todo.tsx` `onTaskDelete` стр. 49-51 + try/catch (новое).
**Apply to:** ветка `!todo.isRepeat`; `rescheduleNextNotification` (стр. 59-61 cancel при ошибке не должен ронять выполнение).

### Read-modify-write по id
**Source:** `storage/todoStorage.ts` `removeTodo`/`updateTodo`.
**Apply to:** `patchTodo`, используется в `handleCompleteTask`.
