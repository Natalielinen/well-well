## Прошедшее время напоминания

**Вопрос 1:** Что делать при сохранении задачи с уже прошедшим временем напоминания?

| Option | Description | Selected |
|--------|-------------|----------|
| Ошибка в форме | Задача не сохраняется, ошибка под полем напоминания (как «Дата не может быть в прошлом») | ✓ |
| Alert с выбором | «Напомнить через минуту / Выбрать другое время» | |
| Сохранить без напоминания | Задача сохраняется, напоминание снимается с сообщением | |

**Вопрос 2:** Время по умолчанию при включении напоминания (сейчас «сейчас» — к сохранению уже в прошлом)?

| Option | Description | Selected |
|--------|-------------|----------|
| Дата задачи + ближайший час | 14:20 → 15:00 на дату задачи | ✓ |
| Пусто до выбора | Сохранить нельзя, пока время не выбрано | |
| Дата задачи, 09:00 | Фиксированное утро | |

**Вопрос 3:** Редактирование задачи, у которой напоминание уже сработало?

| Option | Description | Selected |
|--------|-------------|----------|
| Оставить, не перепланировать | Проверка только если напоминание меняли; время сохраняется для повторов | ✓ |
| Требовать новое время | Ошибка, пока не выбрано новое время или не выключено напоминание | |
| Очистить при сохранении | Прошедшее напоминание молча снимается | |

**Вопрос 4:** Выполнение давно просроченной повторяющейся задачи («Дата в задаче»), следующая дата всё ещё в прошлом?

| Option | Description | Selected |
|--------|-------------|----------|
| Не планировать уведомление | reminderDate сохраняется, уведомления нет; +60 с убирается полностью | ✓ |
| Оставить «через минуту» | +60 с только для выполнения | |
| Ближайшая будущая дата | Сдвигать по repeatFrequency до будущего — ломает контракт единственного сдвига | |
