<objective>
Переработать выполнение задачи в `components/Todo/Todo.tsx`: неповторяющаяся задача отменяет своё уведомление (BUGF-05, D-10), список обновляется сразу после сохранения, а не из кнопки Alert (BUGF-07, D-08), повторяющаяся задача обновляется по актуальной записи из хранилища через новые `getTodo`/`patchTodo` (BUGF-08), сбой перепланирования напоминания не отменяет выполнение (D-07, часть BUGF-09), в алерт выбора даты добавлена «Отмена» (D-09), даты на карточке разбираются локально (BUGF-06, остаток в `Todo.tsx`).

Цель (Purpose): сейчас выполнение неповторяющейся задачи оставляет висящее уведомление удалённой задачи; список обновляется только по нажатию «OK» (на Android Alert закрывается тапом вне окна); `handleCompleteTask` пишет `{ ...todo }` из пропса и затирает правки, сделанные после рендера; исключение перепланирования теряет выполнение при уже отменённом старом уведомлении. Контракт Phase 3/4 сохраняется: `repeatFrequency` прибавляется ровно один раз (D-11, `utils/recurrence.ts` — единственное место сдвига).

Результат (Output): `storage/todoStorage.ts` с `getTodo`/`patchTodo`; `Todo.tsx` с `completeSingleTask`, `handleCompleteTask(base)`, флагом `isCompletingRef`, немедленным `getAllTodos()` и тремя кнопками в алерте выбора даты.
</objective>
